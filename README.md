# SmartSchool Ethiopia 🇪🇹

An integrated school management platform designed to digitalize school services, improve communication between students, parents, and teachers, and provide accessible academic information through a centralized system.

## 📖 About the Project

**SmartSchool Ethiopia** is a web-based school management system developed as part of a Software Engineering project. The system aims to reduce manual school processes, improve information accessibility, and strengthen communication between the school, students, teachers, and parents.

Our team (Group 6) focuses on the student-parent communication and school service modules, integrating with other system components to provide a unified school management experience.

## 🎯 Objectives

- Improve communication between parents, students, teachers, and school administration.
- Provide convenient access to academic information.
- Digitalize announcements, complaints, meetings, and messaging.
- Provide access to learning materials and educational resources.
- Support feedback collection through surveys.
- Deliver timely notifications and reminders.
- Build a centralized, user-friendly, and maintainable platform.

## 🛠️ Technology Stack

SmartSchool Ethiopia is built using modern web technologies, with React for the frontend, Laravel and PHP for backend development, and MySQL for database management.

| Technology | Purpose |
|---|---|
| **React.js** | Interactive and component-based frontend development |
| **Laravel** | Backend framework, routing, authentication, business logic, and API development |
| **PHP** | Server-side programming language |
| **MySQL** | Relational database storage and management |
| **HTML5** | Web page structure |
| **CSS3** | Styling, layouts, and responsive design |
| **JavaScript** | Frontend logic and interactivity |
| **Git & GitHub** | Version control and team collaboration |
| **Visual Studio Code** | Development environment |

### System Architecture

- **Frontend:** React.js
- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Communication:** RESTful APIs
- **Version Control:** Git and GitHub

## 🔐 Security & Access Control

- Role-based access control
- Authenticated user access
- Parent access restricted to linked children
- Students access only their permitted information
- Teachers access assigned classes and academic responsibilities
- Protected messaging and personal data
- Secure API communication and validation

## 🔄 Git Workflow

We use Git and GitHub to collaborate and maintain the project source code.

1. Clone the repository.
2. Create a feature branch for your module.
3. Implement and test your changes.
4. Commit regularly with meaningful commit messages.
5. Push your branch to GitHub.
6. Create a Pull Request.
7. Review and merge into the main branch.
